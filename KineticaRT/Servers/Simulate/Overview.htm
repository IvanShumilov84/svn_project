Simulated inputs are useful for testing and demonstrations. The KineticaRT simulation components are used in most of the KineticaRT demonstrations.

Most of the simulation components have properties for generating more interesting data. For example the sinewave simulator has period and phase properties so that several sine wave channels can be set slightly out of phase with each other or to different periods.

See the SineWave Class, SawToothWave Class, TriangleWave Class, Noise Class and SineArray Class for details.
