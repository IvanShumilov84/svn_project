The KineticaRT OPC Client Library provides components which communicate with any OPC DA Server and allow values to be transmitted and recieved in real time. 

Can be used with very little configuration
Allows real-time multithreaded connection with no application software required.
Can be controlled by KineticaRT Controls e.g. Knob
Can be monitored by KineticaRT Controls e.g. Dial
Supports update rates upto 100Hz

 



OLE for Process Control (OPC) allows access to real-time data from a large number of devices.

There are thousands of OPC servers available from different suppliers. These servers allow access to equipment containing Plant Floor data such as PLC devices and Analog IO cards.

Although OPC was designed for Process Control, OPC servers can provide real-time data from almost any source.

The configurable update rate and grouping of channels provide ease of use.

Although OPC is a COM protocol, KineticaRT has both COM and .NET client components.

See the  Client Class, Group Class and Item Class for details.
