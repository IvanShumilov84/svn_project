The KineticaRT OPC Client Library provides components which communicate with any OPC DA Server and allow values to be transmitted and recieved in real time. 

Multitasking - no missed or delayed messages
Simple logging to text or XML file
Priority system - messages identified by color on display
Alarm sounds and speech - messages read out over the PA system

 



Messages can be generated by the Threshold, Event and Recorder components. These all watch other Channels which are connected using their Source properties.

Messages can be logged to disk using the TextLog and XmlLog components.

The KineticaRT Message Display is easy to configure and receives messages from the other message components. It is updated in real-time and never misses a message. You can embed it straight into your application and its flexible look-and-feel makes it ideal for virtual control panels. 

See the Message Namespace or the Display Class, Recorder Class , Threshold Class and TextLog Class for details.
