The KineticaRT Expression component provides KineticaRT channels that evaluate mathematical and logical expressions involving other channels.

The Value property automaticaly updates whenever an input value changes.

Real time event driven expression evaluation
Standard mathematical expressions
Library of mathematical functions
Time based functions such as Rolling Mean and Standard Deviation
Multitasking & Multiprocessor evaluation


Expressions can include constants, variables, other expressions, server inputs etc. The value of the expression will be re-evaluated as and when its inputs change.

Unlike other real-time systems which continually evaluate all expressions, the KineticaRT Expression component will only use processor time when the inputs to the expression actually change and even then will only re-evaluate the parts of the expression which need re-evaluation.

This makes it especially suitable for use with servers with different update rates and very large numbers of digital inputs which rarely change.
