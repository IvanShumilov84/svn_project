The KineticaRT Channels Library provides components based on the simple KineticaRT Channel but with extended functionality such as minimum and maximum properties on the Numeric allowing the Dial display component to auto-scale when connected.

These extended channels are designed for use in a typical control system.

The Channel classes consist of three basic types - Numeric, Text and Boolean.

For each of these types there are four sub-types - Constant, Variable, Link and Expression.

The Link type provides Source and Destination properties. Either or both can be used to link the channel to another channel such as a server input/output channel.

The Expression type provides an expression Text property and makes use of the Expression library (available seperately) to calculate its value based on the value of other channels.

The extended properties are used by various KineticaRT display components for auto-configuration on connection to a channel. They may also be used by your own application code. 

As well as the above classes there is also a DateTime class which provides the current date and time in various formats.

See the Channels Namespace  for details.
