The KineticaRT Filter component provides Channels which filter the values of another channels.

Low pass, first order linear filter
High pass, first order linear filter
Real time event driven data processing
Multitasking & Multiprocessor evaluation



The components in the KineticaRT Filter library filter data in real-time over a configurable time base.

Data to be filtered often arrives with peaks and troughs masking the required data value. The configurable filter component smooths out these undulations.

The configurable time base provides a flexible and easily maintained smoothing capacity.

See LowPass Class and HighPass Class  for details.
