Add New Channel Collection

Use the Channels / Add New Collection menu to add a new channel file to the current project.

The new Collection will be called "CollectionX".  Select Channels / CollectionX / Rename to give it a sensible name.  The name will be used on the Channel menu and in the channel Explorer.

See Configuring Channels for details on how to add channels to the collection.

The project file must be saved for this setting to be persisted.

Note that the new channel collection should be saved and a filename given before saving the project since the project file needs to contain the filename of the channel collection.
