KineticaRT Display

Features

The KineticaRT Display control provides a numeric or text display and can optionally be connected to a channel.

Unlike the KineticaRT Studio Display control, it does not show a channels description or units.

Its use within KineticaRT Studio is normally limited to the display of captions or labels for other controls, either with fixed text or with the text coming from a channel.

Connection

The KineticaRT Display can be connected to any type of channel.  It will display the channels value in alphanumeric format.
