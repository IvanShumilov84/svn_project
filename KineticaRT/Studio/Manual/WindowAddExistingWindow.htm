Add Existing Window

Use the Window / Add Existing Window menu to add an existing window file to the current project.

If you are using a window file from another project then it is normal to copy the window file into the current project directory and add the local copy.  You can then ship the entire application/project by copying just the project directory.

It is possible to add a single window file twice which can be useful if you have multiple monitors on your PC but it is normally preferable to have a single panel file loaded into multiple window files if you want this functionality.

This setting is stored in the project file so the project must be saved in order to store this setting permanently.
