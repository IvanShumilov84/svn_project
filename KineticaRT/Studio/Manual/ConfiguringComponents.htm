Components

Introduction

A Component is similar to a Control but has no display capabilities, they can be placed on panels in the same way as Controls are but using the "Add Component" menu.  In KineticaRT Studio, examples are the Button Interlock, The Message Voice and the Message Sound components.  An example outside KineticaRT is the Timer Component in Visual Basic. 

Adding Components

Use the right click menu on a panel to enter edit mode and then right click again and select "Add Component" and choose a component from the list.  The list of available components is defined in the project file.

Editing Components

Find the panels Components property in its properties window and click "...".  This will display the Component Collection Editor window, selecting a component from the list on the left will display that components properties on the right hand side of the window.

Note

Currently there is no method of deleting components!   This will be added in the next version but untill then it can be done manually by editing the panels .cs file, deleting the line which adds the component to the components collection, deleting the panels .dll file and restarting.  Saving the panel again will remove all traces of the component.
