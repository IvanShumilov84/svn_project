User Menu

Settings configured from the user menu are user specific and apply to the user currently logged on to Windows.  The settings are stored in the current user section of the Windows registry.  You can therefore disable configuration for certain users while leaving it enabled for other users.

Note that if required, it is possible to prevent a user from modifying the relevant sections of the registry using standard Windows security.

Enable Configurer

This enables the Configurer window for the current user. If it is disabled then it will not appear next time the application is started. Note that the configurer window contains this menu option so once disabled, it can not be turned back on using the menu.

Enable Editing

This enables editing for the current user. If disabled then the "Enter Edit Mode" menu will not be avaiable on the windows.

Enable Explorer

This enables the Explorer window for the current user.
