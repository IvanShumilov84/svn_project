KineticaRT Studio Checkbox

Features

The Checkbox control displays the state of a Boolean (digital) channel and allows the channel state to be changed.

It also has the following features:

  • Display of the channels description or a custom description
  • Display of the channels tooltip or a custom tooltip

Connection

The KineticaRT Studio Checkbox should be connected to channels containing values of type KineticaRT.Values.Boolean.
