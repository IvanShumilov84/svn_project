Add New Window

Use the Window / Add New Window menu to add a new window to the current project.

The new window will be called "New Window".  Select Window / New Window / Rename to give it a sensible name.  The name will be used on the Window menu and in the windows title bar.

The new window will contain a single panel called "Panel 1".  See Configuring Windows and Configuring Panels for more information.

This setting is stored in the project file so the project must be saved in order to store this setting permanently.

Note that the new window should be saved and a filename given before saving the project since the project file needs to contain the filename of the window file.
