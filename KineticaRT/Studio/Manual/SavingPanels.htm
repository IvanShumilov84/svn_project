Saving Panels

  1. Set the filename for the panel by setting the DllName property in the Panel Properties window
  2. Save the panel file by selecting Save from the panels right click menu when in Edit Mode.

Note that if you have added the panel to a window or changed its DllName property then it will be necessary to also save the window since the window file contains a list of panels in the window.  The window must be saved after setting the panel DllName property since this is stored in the window file.

See also: Saving Windows.
