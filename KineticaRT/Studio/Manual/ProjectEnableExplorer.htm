Enable Explorer

Use the Project / Enable Explorer menu to enable or disable the Explorer window.

The Explorer window has the following functions:

  • Shows all the channel collections in the project.
  • Shows all the channels in the channel collections including server channels, expressions, variables etc.
  • Shows the current values of the channels and the values of the channels properties.
  • Allows channels to be added and deleted.
  • Allows the properties of the channels to be modified.
  • Allows the channel configuration to be saved.
  • Provides drag and drop of channels onto display controls.

The Explorer window is normally enabled while configuring an application and may be disabled to prevent the users modifying the configuration.

This setting is stored in the project file so the project must be saved in order to store this setting permanently.
