General Properties

Format

This specifies how to display numeric values as text.  E.g. the KineticaRT Studio Dial has a digital display as well as the needle and this specifies how to display the value digitally.

See Number Formats for more details.

Name

This specifies the name of the control.

The name may be used to access the control from other controls or from sequences.

Source

This specifies the name of the channel supplying the controls current value.

This can also be set by dragging a channel from the channel Explorer onto the control while not in edit mode.

Value

This is the controls current value.

Sometimes a control may not be able to display its current value due to it being out of range or the exact value may not be displayed due to a numeric format being specified.  This property will always show the actual current value.

Other Properties

The other properties are generally not used.
