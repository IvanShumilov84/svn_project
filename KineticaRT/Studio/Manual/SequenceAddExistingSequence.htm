Add Existing Sequence

Use the Sequence / Add Existing Sequence menu to add an existing sequence file to the current project.

Sequence files must have the extension ".cs" for sequence files written in the C# language or the extension ".vb" for sequence files written in the Visual Basic language.

If you are using a sequence file from another project then it is normal to copy the sequence file into the current project directory and add the local copy.  You can then ship the entire application/project by copying just the project directory.

The project file must be saved for this setting to be persisted.
