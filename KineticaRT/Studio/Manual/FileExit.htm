Exit

Use the File / Exit menu to close the KineticaRT Studio application.

You can also use the X (close) button on the application window or possibly on any window depending on project configuration .

Note that you may not be reminded to save certain types of file even if you have made changes to those files. Any changes to these files will be lost.

You can use the File / Save All menu if you are not sure of what needs to be saved.
