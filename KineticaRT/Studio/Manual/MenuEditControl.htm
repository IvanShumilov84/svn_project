The Control Edit Menu

Undo

This undoes the last change made to the panel.

It is actually a multi-level undo which may undo all changes back to the last save or back to the point when you last entered edit mode.

Align

This aligns all the selected control with the master control.

It has sub-menus for:

  • Left - Aligns the left edges of the selected controls.
  • Right- Aligns the right edges of the selected controls.
  • Top- Aligns the top edges of the selected controls.
  • Bottom- Aligns the bottom edges of the selected controls.
  • Horizontal Centre - Aligns the controls vertically.
  • Vertical Centre - Aligns the controls horizontally.

Make Same Size

This makes all the selected controls the same size as the master control.

It has sub-menus for:

  • Width - only makes the widths the same.
  • Height - only makes the heights the same.
  • Both - makes both the width and height the same.

Stack

This option stacks all the selected controls next to each other starting with the master control in its original position.

It has sub-menus for:

  • Horizontal - stacks the controls horizontally
  • Vertical - stacks the controls vertically

Layout

This has the following sub-menus:

  • Snap to grid
  • Size to grid
  • Align to grid
  • Bring to Front - puts the selected controls on top of all other controls.
  • Send to Back  - puts the selected controls beneath all other controls.

Cut

This copies the selected controls to the clipboard and then deletes the originals.

Copy

This copies the selected controls to the clipboard.

Paste

This copies any controls stored in the clipboard onto the panel.

Delete

This deletes the selected controls.

Properties

This displays the controls configuration options.
