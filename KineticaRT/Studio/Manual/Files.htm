Files

The project (Application) directory contains the following types of files:

  • Executable files .exe, .dll
  • The Project file .ksp
  • Window files .ksw
  • Channel files .ksc
  • Sequence files .cs, .vb

Executable Files

There are several types of executable file:

  • The application .exe
  • Application dlls
  • Panel dlls
  • Sequence dlls

The original application .exe file is named KineticaRT.Studio.exe but this can be renamed to whatever you wish.  When the application is started, by opening this file, it will look for a project file with the same name and a .ksp extension.

The application dlls contain the application software and the software for the controls and channels.  You can add extra controls and channels to the application by including their dlls and adding a reference to them into the project file.

The panel and sequence dlls are generated by KineticaRT Studio when it compiles the panels and sequences into .net executable code.

None of these files can or should be edited other than changing the name of the application.

The Project File

This file contains various project settings and also defines all the other files to be loaded as part of the application.

Most of the contents of this file can be configured from within KineticaRT Studio, the rest are listed below and can be modified using any text editor:

ShowConfig Attribute

If you have turned off the configuration window to prevent user configuration, you can set this to "1" to switch it back on again.

Addable Controls Section

This section contains two types of item, "Add"  and "Reference" .

The Add items define the list of controls which can be added to the panels using the panels right click / Add menu.  You can remove items from this list if you don't wish the user to be able to add them or add extra items.  All items in this list must be .net Windows Forms Controls.

The Name attribute defines the name shown on the Add menu.

The Type attribute defines the .net type (class) of the control.

The "Reference" items define the list of dlls containing the controls.  The dlls must be placed in this list to allow the controls to be saved and re-loaded.

Window Files

There is one of these for each window and each contains the window settings and a list of panels displayed on the window.

There is no reason to edit these other than with the menus in KineticaRT Studio.

Channel Files

These contain lists of channels and their property values.

There is normally no reason to edit these except by using the channel explorer within KineticaRT Studio.

They are produced and read using the .net XML serializer and can be modified/created externally as long as the format remains compatible with XML Serialization.

Sequence Files

These are either in C# (.cs) or Visual Basic .net (.vb) source code format.  You cannot put Visual Basic code in the .cs files or C# code in the .vb files but you may have both types in the same application.

These can be edited in any text editor, KineticaRT Studio does not provide its own editor.

When the application is loaded, any updated sequence files will be automatically compiled into the executable sequence .dll files ready to be executed.  Compilation can not be performed while the application is running.

See Sequences for information on the format and methods available for use in KineticaRT Studio Sequence files.
