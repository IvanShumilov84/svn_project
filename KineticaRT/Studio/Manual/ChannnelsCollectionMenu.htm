Channel Collection Menu

Each channel collection installed in the project has its own sub-menu under the main Channels menu, identified by its name.

Each channel collection sub-menu has the following options:

  • Rename
  • Edit
  • Save
  • SaveAs
  • Remove

Rename

Use this submenu to rename the collection.  The collection name is used in the channel Explorer and on the Channels menu.  It can also be used in expressions and display objects to distinguish between channels with the same name but located in different collections.

The project file must be saved for this setting to be persisted.

Note

There is currently a bug in the renaming software so that the channel collection will disapear until you restart the application.  After renaming, you should save the project file and then restart.

Edit

This option opens the channel Explorer and selects the chosen collection.

Save

Saves the channel collection settings to the channel collection file.

SaveAs

Saves the channel collection settings in a new channel collection file.  The new filename will be remembered, used by the Save menu and saved in the project file if the project file is saved.

Remove

This removes the channel collection from the project.

The project file must be saved for this setting to be persisted.
