Save

Use the Project / Save menu to save the current project configuration to the project file.

The project configuration includes:

  • Enable/Disable Explorer window
  • Enable/Disable Configurer window
  • Enable/Disable Window Closedown
  • Window List
  • Channel Collection List
  • Sequence List

Note that the project file does contain other project information not listed above.
