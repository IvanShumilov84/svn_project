Event Handlers

In KineticaRT Studio, Event Handlers are located in the Sequence files and written in the C# or Visual Basic .net languages.

In previous versions of KineticaRT we have had action lists available on controls such as buttons. In KineticaRT Studio actions are implemented using the sequences.

Advantages of using C# for sequences and event handlers:

  1. C# is a standard .Net language.
  2. C# is a strongly typed language making most of the programming errors of C++ impossible while retaining the flexibility.
  3. C# is widely used for .Net development. (Probably the most widely used next to Visual Basic.)
  4. C# is fully compatible with Visual Studio .Net, all third party .Net software components and allows access to all operating system facilities.
  5. There are many C# books and training courses available.

The same list applies if you want to use the Visual Basic language.

KineticaRT Studio sequences are developer or user written .Net classes based on the KineticaRT Studio Sequence base class. The base class provides various methods to make the development of test sequences easy. Use of multithreaded sequences is straightforward.

Example of Using Buttons with Sequences and Event Handlers

The following example is in C# source code and may be used within a KineticaRT Studio sequence file. For help on the language see Microsoft documentation, C# books and the help files for KineticaRT and the KineticaRT Sequence component:

class TestSequence1 : Sequence
{
	KineticaRT.Channels.Channel b1 ;
	KineticaRT.Channels.Channel b2 ; 
	KineticaRT.Channels.Channel n1 ; 

	// Called by KineticaRT Studio on initialization. 
	public override void Connect () 
	{ 
		base.Connect () ; 
		System.Diagnostics.Trace.WriteLine ("TestSequence1: Demonstrate use of buttons") ; 
		// Find the control channels - quicker to do this during startup than continuously. 
		b1 = GetChannel ("Controls.Run") ; 
		b2 = GetChannel ("Controls.Reset") ; 
		n1 = GetChannel ("Value") ; 
		if ((b1 == null) || (b2 == null) || (n1 == null)) 
		{ 
			System.Diagnostics.Trace.WriteLine ("TestSequence1: Missing Channels") ;
			return ; 
		} 
		
		// Initialise our control 
		channels. b1.Value = Values.False ; 
		b2.Value = Values.False ; 
		n1.Value = Values.Zero ; 
		
		// Start our monitoring thread(s). 
		StartThread (new ThreadStart(MainThreadMethod)); 
		
		// Connect our event handler(s). 
		b2.ValueChanged += new KineticaRT.Channels.ValueChangedEventHandler(OnReset); 
	} 

	// This method increments "Value" 10 times per second whenever any run button is pressed. 
	void MainThreadMethod() 
	{ 
		while (true) 
		{ 
			Wait (b1) ; // Wait for b1 (run button) to be pressed. (Wait is a KineticaRT Sequence method.) 
			n1.Value ++ ; // Increment “Value”. 
			if (n1.Value > 100) 
			{ 
				n1.Value = Values.Zero ; 
			} 
			Wait (100) ; // One hundred milliseconds. 
		} 
	}
	
	// This method (event handler) is called when any reset button is pressed or released and resets "Value" if the button was pressed. 
	private void OnReset (KineticaRT.Channels.IChannel sender, KineticaRT.Values.Value newVal) 
	{ 
		if (newVal == Values.True) n1.Value = Values.Zero ; 
	} 
}
