Application

All executable and configuration files are contained in a single folder which can be copied, duplicated etc as a whole.

Items that can be configured at application level are described below.

Splash Screen Logo

The splash screen is displayed while the project is being loaded and the text within it is updated to show the loading progress.

The image displayed within the splash screen can be changed from the default by adding an image file containing the new image to the application folder. This file must be called "logo.gif".

The splash screen can be removed completely by removing the file KineticaRT.Studio.Splash.dll from the folder.

The file KineticaRT.Studio.Splash.dll could also be replaced by a custom dll file if a different layout or extra functionality is required. An example C# file is available for use as a base for creating a new version.
