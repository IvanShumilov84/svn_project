Window Menu

Each window installed in the project has its own sub-menu under the main Window menu, identified by its name.

Each window sub-menu has the following options:

  • Rename
  • Properties
  • Select
  • Save
  • SaveAs
  • Remove

Rename

Use this submenu to rename the window.  The window name is used in the windows title bar and on the Window menu.

The project file must be saved for this setting to be persisted.

Properties

This submenu brings up a properties dialog for the window.  This gives the following window options:

  • Show In Taskbar
  • Show Controls

Show In Taskbar

If checked then the Window will appear on the Desktop Taskbar.

Show Controls

If checked then the Window will have the Minimise, Close etc buttons on its titlebar.

Select

This option ensures the window is displayed on the screen and sets the input focus to it.

Save

Saves the window settings to the  window file.

SaveAs

Saves the window settings in a new window file.  The new filename will be remembered, used by the Save menu and saved in the project file if the project file is saved.

Remove

This removes the window from the project.

The project file must be saved for this setting to be persisted.

Note

Currently, saving the window file also saves the windows position (on the screen), size and state.  This information is likely to be stored in the project file in the next version.
