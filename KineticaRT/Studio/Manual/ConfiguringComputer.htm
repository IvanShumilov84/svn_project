Transition Effects

For best display performance, the Windows transition effects should be turned off in the Windows Control Panel. This is because while Windows is performing a Transition Effect it prevents all other screen updates and thus causes a pause in the display of live data.

You can disable "Transition Effect"s in the Windows Control Panel / Display / Appearance / Effects... / Use transition effects.
