Sequence Menu

Each sequence installed in the project has its own sub-menu under the main Sequence menu, identified by its name.

Each sequence sub-menu has the following options:

  • Rename
  • Edit
  • Remove

Rename

Use this submenu to rename the sequence.  The sequence name is used in for referencing the sequence from other sequences and on the Sequence menu.  This will not rename the sequence file or the sequence class name.  Renaming sequence is generally not recommended.

The project file must be saved for this setting to be persisted.

Edit

This option opens the sequence source code file into your default editor for files with the sequence filename extension.  The default ".cs" file editor or the default ".vb" file editor.  If you have Microsoft's Visual Studio installed then they will be opened in the Visual Studio editors.  If you have no default editor for .cs files then you can configure the Windows default to be Windows Notepad or your favorite text / code editors by opening a .cs file from Windows Explorer.

Once the sequence file has been edited, make sure the file has been saved.  The project must then be reloaded in order to compile and load the new sequence.  Sequences can not be updated while the application is running in this version on KineticaRT.

The sequence source file will only be compiled if its modification date is later than the modification date on the sequence executable (.dll) file.

Remove

This removes the sequence from the project.

The project file must be saved for this setting to be persisted.
