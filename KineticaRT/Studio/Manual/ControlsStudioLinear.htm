KineticaRT Studio Linear

Features

The Linear control displays the value of a numeric channel.  It can optionally allow new values to be entered using either the mouse or keyboard.

It has the following features:

  • Display of the channels description or a custom description
  • Display of the channels tooltip or a custom tooltip
  • Display of the channels units.
  • Display of the channels values using a needle.
  • Display of the channels value using a digital display
  • Optional display of the channels value using fill
  • Optional entry of new values using slider (mouse) and digital (keyboard)

Connection

The KineticaRT Studio Linear should be connected to channels containing values of type KineticaRT.Values.Double.
