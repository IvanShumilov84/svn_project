Add Existing Channel Collection

Use the Channels / Add Existing Collection menu to add an existing channels file to the current project.

If you are using a channels file from another project then it is normal to copy the file into the current project directory and add the local copy.  You can then ship the entire application/project by copying just the project directory.

Each channel file contains a collection of channels to be loaded into the project. 

There is no need to use multiple channel files but it can make it easier to perform the following actions:

  • Copy a group of channels between projects, e.g. all the channels for an OPC server.
  • Replace a group of channels by a set of simulated channels with the same names.  Especially useful if you don't have access to a real data source during development and testing.
  • Disconnect/Reconnect a group of channels to diagnose a problem.

The project file must be saved for this setting to be persisted.
