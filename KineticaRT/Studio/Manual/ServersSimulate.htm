KineticaRT Simulate

Features

The KineticaRT Simulate components provide simulated inputs for testing and demonstration use when real inputs are not available.

There are several components providing different values:

  • SawToothWave
  • SineArray
  • SineWave
  • TriangleWave

 

Most of the components provide numeric values suitable for use on most display controls.

The SineArray provides an array of numeric values suitable for display on the Bargraph control.

They have properties for adjusting the minimum and maximum values generated and the period and phase of the waves produced.
