KineticaRT Studio ErrorLinear

Features

The ErrorLinear control displays the difference in value between two numeric channels.

It is intended for use where a process is being controlled and a one channel has to reach a set point value stored in a second channel.

It has the following features:

  • Display of one channels description or a custom description
  • Display of one channels tooltip or a custom tooltip
  • Display of one channels units
  • Display of the difference in values between the two channels using a needle
  • Display of the difference in values between the two channels using a digital display
  • Optional display of the difference in values between the two channels using a linear fill.

Connection

The KineticaRT Studio ErrorLinear should be connected to channels containing values of type KineticaRT.Values.Double.
