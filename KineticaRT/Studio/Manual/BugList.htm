Bug List

This is a list of the known bugs / features.  Unless otherwise stated, they are due to be fixed in the next version.

Bargraph leaves untidy display

When changing the number of columns in the source data array, the Bargraph can leave old data on the display.

Panels have no way of deleting components

If you add components (Not Controls) to a panel, there is no way of deleting them - see note here.

Default Visual Basic Sequence is in C#

It is necessary to translate the default sequence into VB before it will work.
