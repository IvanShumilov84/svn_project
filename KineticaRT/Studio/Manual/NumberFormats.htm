Specifying Number Formats

  • F - Fixed Format
  • G - General Format
  • C - Currency Format

These formats can be followed by a digit to specify how many digits or digits after the decimal place to display.

E.g..  With a value of 34.5678,

F2 would give 34.56.

G2 would give 34

C would give £34.56 (on a UK computer).
