Enable Window Closedown

Use the Project / Enable Window Closedown menu to enable or disable exiting of the application using the X buttons in the title bar of the windows.  If disabled then the application can only be closed from the Configurer window or a Sequence and the X buttons will only minimize their own Windows.

This setting is stored in the project file so the project must be saved in order to store this setting permanently.
