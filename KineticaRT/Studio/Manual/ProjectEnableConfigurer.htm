Enable Configurer

Use the Project / Enable Configurer menu to enable or disable the Configurer window.  This is the window with the Project / Enable Configurer menu on it.

The Configurer window has the following functions:

  • Provides the KineticaRT Studio main menu thus giving access to all configuration functions.
  • Contains a debug window which displays diagnostics messages.
  • Provides a way of closing the application if all other methods are disabled.

The Configurer window is normally enabled while configuring an application and may be disabled to prevent the users modifying the configuration.

Note that if the Configurer is disabled, it will not disappear until the application is restarted.

This setting is stored in the project file so the project must be saved in order to store this setting permanently.

To get the Configurer window re-enabled once saved, you must edit the project file using a text editor such as windows notepad and change ShowConfig="0" to ShowConfig="1".
