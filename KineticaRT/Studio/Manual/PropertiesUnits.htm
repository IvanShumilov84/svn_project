Units Properties

These define the value of the units display on KineticaRT.Studio controls.

  • CustomUnits
  • Units
  • UseCustomUnits

If the UseCustomUnits property is set to True then the control will display the value entered in the CustomUnits property otherwise it will use the value from the Units property.

The value in the Units property is the value actually in use.  This can not be set directly.
