# The #ziblib file

You need to distribute zip.dll with zipped applications
When you run netz the compressed files are placed in a folder named after the exe file + ".netz"

The zip.dll file is a recompiled version of ICSharpCode.SharpZipLib.dll source code, that contains only ZIP support.
