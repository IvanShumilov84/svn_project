The KineticaRT Knob is fast, easy to configure and supports live update. You can embed it straight into your application and its flexible look-and-feel makes it ideal for virtual control panels.

Manual input capability (mouse dragging)
Destination property allows connection to channel component
Source property allows feedback channel to automatically update display
Circular Scale can show text, roman numerals, compass points etc. and display threshold marks


The KineticaRT Knob is a real-time multi-threaded control that can be embedded straight into your application or onto a KineticaRT Frame component to allow run-time configuration.

As with other KineticaRT controls width and height are configurable, as well as the colors of the separate parts of the knob.

This multi-purpose control has three different background shape and style options and can also be configured as constant value or auto-return.

If configured to read a source channel, the knob will rotate to show the value against the scale. If a destination channel is selected, that channel will be updated with the value of the knob.
