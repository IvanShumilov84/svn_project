The KineticaRT Picture is fast, easy to configure and supports live update. You can embed it straight into your application and its flexible look-and-feel makes it ideal for virtual control panels.

Single image or multi-frame animation
Color substitution
Value proportional fill of a region
Ideal for mimic diagrams and value indicators
Can be used on the KineticaRT Button component


The KineticaRT Picture is a real-time multithreaded control that displays a single image or multi-frame animation. It can be embedded straight into your application or onto a KineticaRT Frame component to allow run-time user configuration.

Pictures can be animated, with configurable frame rate, and the colors of chroma-keyed regions controlled to indicate changes of state of a channel. These features make it ideal for use as an indicator display.

Another chroma-keyed region can be used as an analog indicator that fills vertically in proportion to the value of a channel.

As with other KineticaRT controls, you can choose from a number of shape, appearance and border style options. There are also properties for image size and alignment.

With the Pictue component installed, all the features above become available on the KineticaRT Button component.
