XY Graph Properties Demonstration

The KineticaRT XY Graph has many configuration properties including Shape, Border Style, Gridmarks, Thresholds, Range and Trace configuration.

These properties can be configured using the property explorer or configured in code. The selection boxes on this demonstration allow you to modify several of the standard settings. If you wish to view or modify any additional properties press the Properties >> button which will display a property explorer containing all the indicator's properties.

The KineticaRT XY Graph component is able to have one or more traces. These can be connected to any KineticaRT logic or server component such as a data channel or an OPC server using the trace's source property.

In this demonstration the XY Graph has one trace, which is connected automatcially to a sinewave located in the KineticaRT.Servers.Simulate library, or manually to the slider. The traces update in value without having to write any additional event handling code. The only code that is required is the initial connection of the trace to the sinewave : -

e.g.
XYGraph1.Traces[0].XSourceChannel = sineWaveX;
XYGraph1.Traces[0].YSourceChannel = sineWaveY;
