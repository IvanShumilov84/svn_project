The KineticaRT Dial is fast, easy to configure and supports live update. You can embed it straight into your application and its flexible look-and-feel makes it ideal for virtual control panels.

Configurable needle with smooth movement
Optional colored fill - solid, segmented or permanent
Labelled scale with optional threshold marks
Text scale labels - for roman numerals, compass points etc.
Manual input - drag the needle to update the destination channel
Source property updates display in real-time


The KineticaRT Dial is a real-time multi-threaded control that can be embedded straight into your application or onto a KineticaRT Frame component to allow run-time user configuration.

As with other KineticaRT controls width and height are configurable, as well as the color of each part of the dial.

Scale start and sweep angle can be specified and adjusted at runtime.

There are several needle styles with configurable length, width and color. Colored fill can be added with a specified position, width and style. Segmented fill changes color at threshold marks.

Two text regions on the dial face can show, for example, description, units or scale multiplier.

If the dial's Source property is connected to a channel, the dial will automaticaly move its needle to match the value of the channel with no need for any application code. The Destination property allows the value of the dial to be sent to another channel.

Drag and drop allows a source channel to be attached to the dial. Auto configuration can set scale, description and units.
