The KineticaRT Display is fast, easy to configure and supports live update. You can embed it straight into your application and the flexible look-and-feel makes it ideal for virtual control panels and data entry applications.

Displays text strings, formatted numeric values, dates and times
Manual keyboard input - for run-time value editing
Source property updates the display in real-time


The KineticaRT Display is a real-time multi-threaded control that can be embedded straight into your application or onto a KineticaRT Frame component to allow run-time user configuration.

As with other KineticaRT controls width and height are configurable, and in this case the font face and style can be configured.

The text display can be oriented in different directions - up, down, left or right and spin buttons can be configured for multi-line text capability.

In its input form it can display numerics, text, time and date formats also the results of KineticaRT expressions.

When used as data entry, the data can be validated at run-time to check minimum and maximum allowed entries, formats and also text length.

The Destination property allows the content of the control to be sent to another component or channel.
