The KineticaRT Bargraph is fast, easy to configure and supports live update. You can embed it straight into your application and the flexible look-and-feel makes it ideal for virtual control panels. It is typicaly used to display values from an array of sensors. 

Configurable number of bars with different color options
Optional description text and numeric value repeater for each bar
Linear Scales - left and right with optional threshold marks


The KineticaRT Bargraph is a real-time multi-threaded control that can be embedded straight into your application or onto a KineticaRT Frame component to allow run-time configuration.

The number of vertical bars is configurable, limited only by the size of the object.

The bars can have an optional numeric display echoing the value displayed by the bar, and each bar can have its bar number attached.

Dividing scale lines and spaces between bars are configurable.

The left and right scales are optional and can be different, and have text or numeric labels.

Data is provided as an array of numeric values with one array item for each bar. It may be connected to a KineticaRT array channel such as the SineArray in the Simulate library.
