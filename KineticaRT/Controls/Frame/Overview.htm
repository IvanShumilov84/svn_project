The KineticaRT Frame Control is a container for other Controls. It provides all the standard container features and many more.

Control Container
Runtime Editing
Automatic control positioning/sizing
Save to configuration files and reload
Grid and layout commands


The KineticaRT Frame acts as a container to any number of controls.

There is a comprehensive selection of formatting and positioning commands allowing alignment, spacing and sizing of controls relative to each other.

An optional title bar is available which which may be shaded.

The configuration of each control and of the frame itself can be saved to an XML format file.

See  Frame Class for details.
