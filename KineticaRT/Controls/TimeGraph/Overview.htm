The KineticaRT TimeGraph is fast, easy to configure and supports live update. You can embed it straight into your application and its flexible look-and-feel makes it ideal for virtual control panels.

Labelled scale with optional threshold marks
Text scale labels - for roman numerals, compass points etc.


The KineticaRT TimeGraph is a real-time multi-threaded control that can be embedded straight into your application or onto a KineticaRT Frame component to allow run-time user configuration.

As with other KineticaRT controls width and height are configurable, as well as the color of each part of the TimeGraph.

See  TimeGraph Class for details.
