The KineticaRT Indicator is fast, easy to configure and supports live update. You can embed it straight into your application and its flexible look-and-feel makes it ideal for virtual control panels.

Different shapes (rectangle, rounded rectangle or ellipse)
Different styles (raised, flat or indented)
Different colors corresponding to different values or value ranges.
Source property for connection to digital input etc.


The KineticaRT Indicator is a real-time multi-threaded control that can be embedded straight into your application or onto a KineticaRT Frame component to allow run-time configuration.

It is primarily used to indicate the boolean (on/off) state of a source channel, but can also be used to indicate different values of the source by displaying different colors controlled by states.

As with other KineticaRT controls width and height are configurable, and this control has three different background shape and style options.

It can be configured to remain a constant color after the source changes, even if the value reverts later, or it can follow every change (auto-return).

The Destination property allows the value of the indicator to be sent to a channel.

See Indicator Class for details.
