The KineticaRT Button is fast, easy to configure and supports live update. You can embed it straight into your application and its flexible look-and-feel makes it ideal for virtual control panels. 

Choice of operating modes - latched, auto-return or sticky
Interlocking - by using the KineticaRT Button Interlock component
Picture buttons - with the KineticaRT Picture component installed
Separate pictures for up, down and disabled states
Picture animation, color substitution and proportional fill of a region


The KineticaRT Button is a real-time multi-threaded control that can be embedded straight into your application or onto a KineticaRT Frame component to allow run-time user configuration.

This multi-purpose control has three different shape options and can be configured as a check box, radio button or standard push button.

With three operating modes - latched, auto-return or sticky - the button offers excellent flexibility for use in virtual control panel applications.

Multi-line horizontal or vertical text labeling is available or, with the KineticaRT Picture component installed, pictures can be applied to each state of the button.

Pictures can be animated or the colors of chroma-keyed regions can be changed to indicate changes of state of a channel.

When used with the KineticaRT Button Interlock component you can interlock multiple buttons or radio buttons.

As with other KineticaRT controls width and height are configurable, as well as the color of each part of the control.
